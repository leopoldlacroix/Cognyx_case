</acceptance_criteria>

<action>
In `app/services/ingestion.py`, implement:

```python
import hashlib
from pathlib import Path

def compute_file_hash(file_path: Path) -> str:
    """Compute SHA-256 hash of file contents."""
    hasher = hashlib.sha256()
    with open(file_path, 'rb') as f:
        for chunk in iter(lambda: f.read(8192), b''):
            hasher.update(chunk)
    return hasher.hexdigest()
```

Implement `register_source_file(conn, source_system, file_name, file_hash, ingested_at)`:
- INSERT OR IGNORE into source_file (source_system, file_name, file_hash, ingested_at)

- If IGNORE (duplicate): SELECT id FROM source_file WHERE source_system=? AND file_hash=?
