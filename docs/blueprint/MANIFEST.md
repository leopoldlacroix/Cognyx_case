# Package Manifest

## Deliverable

`cognyx_poc_blueprint/`

## Included

- complete product/architecture scope;
- relational data model specification;
- ingestion + normalization pipeline specification;
- reconciliation worker specification;
- human-in-loop workflow;
- canonicalization + technical facts + reuse analysis;
- UI specification;
- backend/API contracts;
- synthetic data design;
- test/validation strategy;
- execution roadmap;
- production evolution notes;
- coder and demo checklists;
- example normalization configuration;
- sample reconciliation scenarios.

## Explicitly excluded

- production source code;
- database migration code;
- LLM prompts intended as final implementation code;
- frontend components;
- deployment manifests;
- external system credentials/configuration;
- proprietary customer data.

The package is intended to be consumed as the implementation specification for the PoC.
